# 收支表格小铺 · 单月收支月报
这份Excel样例由本项目制作，包含可编辑的收支明细和自动汇总月报。所有演示流水均为虚构。
创作者主页与后续商品说明见 [爱发电收支表格小铺](https://afdian.com/a/simplecashflow)。
当前仓库公开提供完整样例，可直接下载试用。后续定制整理服务需先核实需求、范围和交付时间。

## 使用方法
1. 下载Excel文件并另存一份，每份文件只记录一个月。
2. 打开“收支明细”，清除第2行起的示例内容，保留表头。
3. 按日期、摘要、分类、收入、支出填写。收入和支出均填非负数，未发生的一侧填0。
4. “月报”自动统计明细第2至10001行，新增记录须在这个范围内。
5. 本人账户互转、借款、退款需先明确统计口径，避免重复计算。结余反映录入的现金收支。

## 已验证的示例
示例收入180+260=440元，支出12+95+18=125元，结余315元。文件导出后重新打开，三项结果均已核对。
未提供税务申报或复式会计功能。月报统计整个明细页的金额，需自行保证为同一月份。

## 数据保护
请先删除姓名、银行卡号、账户标识、手机号、订单号等信息，再发送来稿。公开仓库仅包含虚构数据。
